## 구현 기능 목록

### 1. 자동차 이름 입력
#### 1-1. 입력 받기
- [ ] 사용자로부터 경주할 자동차 이름 문자열을 입력받는다.

**예외처리**
- [ ] 입력이 비어있는 경우 `IllegalArgumentException` 발생
  - 오류 메시지: `[ERROR] 자동차 이름을 입력해 주세요.`

---

#### 1-2. 문자열 파싱
- [ ] 쉼표(,)을 기준으로 문자열을 분리한다.
- [ ] 각 이름의 앞뒤 공백을 제거한다.
- [ ] 빈 문자열을 제외하고 유효한 이름만 수집한다.
- [ ] 분리된 이름 목록을 반환한다.

**입력 예시**
```
입력: "pobi,woni,jun"     → ["pobi", "woni", "jun"]
입력: "pobi, woni, jun"   → ["pobi", "woni", "jun"] (공백 제거)
입력: "pobi,,jun"         → ["pobi", "jun"] (빈 문자열 무시)
입력: "pobi, ,jun"        → ["pobi", "jun"] (공백만 있는 것도 무시)
입력: ",,pobi,,jun,,"     → ["pobi", "jun"] (모든 빈 문자열 무시)
```

**예외처리**
- [ ] 파싱 후 유효한 이름이 하나도 없는 경우 `IllegalArgumentException` 발생
  - 예: `",,"`, `", ,"`, `" , " `
  - 오류 메시지: `[ERROR] 최소 1대 이상의 자동차가 필요합니다.`

---

#### 1-3. 개별 이름 검증
- [ ] 각 자동차의 이름이 유효한지 검증한다.
- [ ] 자동차 이름은 쉼표를 제외한 모든 문자를 허용한다.
- [ ] 자동차 이름은 1글자 이상 5글자 이하여야 한다.

**검증 예외 처리**
- [ ] 자동차 이름이 5글자를 초과하는 경우 `IllegalArgumentException` 발생
  - 예: `"soohyuncar"`
  - 오류 메시지: `[ERROR] 자동차 이름은 5글자 이하만 가능합니다.`

---

#### 1-4. 전체 목록 검증
- [ ] 중복된 자동차 이름이 없는지 확인한다.

**전체 검증 예외 처리**
- [ ] 중복된 자동차 이름이 있는 경우 `IllegalArgumentException` 발생
  - 예: `"pobi, womi, pobi"`
  - 오류 메시지: `[ERROR] 자동차 이름은 중복될 수 없습니다.`

---

### 2. 시도 횟수 입력
#### 2-1. 입력받기
- [ ] 사용자로부터 시도 횟수를 입력받는다.
- [ ] 입력된 문자열을 정수로 변환한다.

**예외 처리**
- [ ] 입력이 비어있는 경우 `IllegalArgumentException` 발생
  - 오류 메시지: `[ERROR] 시도 횟수를 입력해주세요.`
  
---
#### 2-2. 시도 횟수 검증
- [ ] 시도 횟수의 값이 유효한지 검증한다.

**예외 처리**
- [ ] 숫자가 아닌 값을 입력한 경우 `IllegalArgumentException` 발생
  - 예: `"abc"`,`"3.5"`
  - 오류 메시지: `[ERROR] 시도 횟수는 숫자여야 합니다.`
- [ ] 1미만의 수를 입력한 경우 `IllegalArgumentException` 발생
  - 예: `"0"`,`"-5"`
  - 오류 메시지: `[ERROR] 시도 횟수는 1 이상이어야 합니다.`

---

### 3. 경주 진행
#### 3-1. 게임 초기화
- [ ] 입력받은 자동차 이름으로 Car 객체를 생성한다.
- [ ] 모든 자동차의 초기 위치는 0이다.
- [ ] Cars 객체에서 자동차 목록을 담는다.

---

#### 3-2. 라운드 진행
- [ ] 시도 횟수만큼 라운드를 반복한다.
- [ ] 각 라운드마다 다음을 수행한다.
- [ ] 모든 자동차에 대해 전진 시도를 한다.
- [ ] 현재 라운드의 결과를 출력한다.

---
#### 3-3. 자동차 전진 로직
- [ ] 각 자동차마다 0~9 사이의 무작위 숫자를 생성한다.
  - `Randoms.pickNumberInRange(0,9)` 사용
- [ ] 생성된 숫자가 4 이상이면 자동차가 1칸 전진한다.
- [ ] 생성된 숫자가 3 이하이면 자동차는 정지한다.(이동 없음)

---

### 4. 결과 출력
#### 4-1. 라운드별 결과 출력
- [ ] 각 라운드마다 모든 자동차의 상태를 출력한다.
- [ ] 자동차 이름과 현재 위치를 출력한다.
- [ ] 위치는 `-` 기호로 표시한다. (위치가 3이면 `---`)

**출력 양식**
```
실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --
```

---

### 4-2. 최종 우승자 결정
- [ ] 모든 라운드 종료 후 가장 많이 전진한 자동차를 찾는다.
- [ ] 최대 위치값을 가진 자동차가 우승자이다.
- [ ] 동일한 최대 위치를 가진 자동차가 여러 대면 모두 우승자이다.

---

#### 4-3. 우승자 출력
- [ ] 우승자를 출력한다
- [ ] 우승자가 1명인 경우: `최종 우승자 : {name}`
- [ ] 우승자가 여러 명인 경우: `최종 우승자 : {name1}, {name2}, {name3}`
  - 쉼표와 공백으로 구분

---
